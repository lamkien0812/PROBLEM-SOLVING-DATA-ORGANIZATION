# Demo Script

1. Open the project in VS Code.
2. Run `npm test` and show the passing test cases.
3. Run `npm start`.
4. Select `1` to demonstrate the five basic algorithms.
5. Select `2` to demonstrate Map, Min Heap, and LRU Cache.
6. Select `3` to compare BFS and A* on the same maze.
7. Select `4` to run the real benchmark.
8. Open `data/benchmark_results.csv` and explain the measured times and visited cells.
9. Explain the complexity table in `COMPLEXITY.md`.
